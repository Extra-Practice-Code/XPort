Markdown cheatsheet

Emphasis:
*italic*
**bold**

Links:
<http://www.example.com/>
[example](http://www.example.com/)

Titles:
# Header 1
## Header 2
### Header 3

Linebreaks are not shown by default.

Separate pargraphs with an empty line.

Make a forced linebreak by inserting two spaces at the end of a line.

Blockquoute:
> Find a place you trust, and then try trusting it for awhile.

Lists:
- Item
- List Item
- Another List Item
    - A sub list is made
    - By inserting four spaces

Numbered lists:
1. First item
2. Another item
3. Item nr. 3

Horizontal line:
---

[[ tag ]]
[[ tag | label to show ]]
